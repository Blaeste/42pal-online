Assignment name  : repeat_twice
Expected files   : repeat_twice.c
Allowed functions: write
--------------------------------------------------------------------------------

Write a program that takes a string and displays it 2 times, separated by
spaces, followed by a newline.

If the number of arguments is not 1, the program displays a newline.

Examples:

$>./repeat_twice hello | cat -e
hello hello$
$>./repeat_twice "ab c" | cat -e
ab c ab c$
$>./repeat_twice | cat -e
$
